# Ent-LoRD: Reproducibility Artifacts

This repository is intended to host the implementation and reproducibility artifacts for Ent-LoRD.

The artifact package is being prepared for the full-paper submission. It will include expert-pruning and allocation code, model export and serving configurations, evaluation scripts, and instructions for reproducing the reported experiments.

The repository will be updated with the available artifacts by the full-paper submission deadline.
